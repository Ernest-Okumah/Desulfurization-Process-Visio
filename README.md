# Desulfurization Process Design
## Project Overview 
This project presents a desulfurization process design developed using Microsoft Visio.
The work illustrates the process flow involved in removing sulfur compounds from industrial streams to reduce environental pollution and improve process efficiency.
## Objectives 
- To design a clear process flow diagram(PFD) for desulfization 
- To demonstrate the major unit operations involved in sulfur removal.
- To improve understanding of industrial gas treatment and purification process.
## Software Used 
- Microsoft Visio 
## Project Content 
- Process Flow Diagram 
- Equipment Layout and Connections
- Stream flow presentation 
## Applications 
Desulfurization processes are widely used in:
- Oil and gas industries 
- Petroleum refineries
- Natural gas processing plants
- Environmental pollution control system
